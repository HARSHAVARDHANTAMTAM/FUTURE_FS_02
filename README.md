# Mini CRM System

## Live Demo
Frontend:
https://future-fs-02-six-self.vercel.app

Backend:
https://future-fs-02-m4r2.onrender.com

## Features
- JWT Authentication
- Lead Management
- CRUD Operations
- Lead Status Updates
- Search & Filtering
- Protected Routes
- MongoDB Atlas Integration

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Render
- Vercel

## Installation

### Client
npm install
npm run dev

### Server
npm install
node server.js
